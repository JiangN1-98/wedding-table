# 喜席 · 婚礼座位安排

使用 React 19、TypeScript、Tailwind CSS 4 和 Vite 开发的婚礼圆桌排座工作台。

## 本地运行

推荐 Node.js 22.18+ 或 24。

```bash
npm install
npm run dev
```

以终端显示的本地地址为准，默认端口为 5173。

```bash
npm run build  # 类型检查与生产构建，生成 dist/
npm run lint   # 代码检查
npm test       # 座位分配和数据完整性测试
npm run preview
```

## 功能

- 导入 `.xlsx`、`.xls` 或 `.csv` 名单，先预览后追加，支持最大 5 MB、每次 2000 位宾客。
- 下载带填写示例、分组下拉选项和说明的 Excel 模板。
- 表单添加、编辑、删除宾客，包含姓名、分组、手机号和备注。
- Excel 可选填「桌号」（1～200），自动安排到对应桌子并补建缺少的桌子；满桌宾客保留待安排，预览显示入座与满桌人数。
- 按姓名、手机号、备注搜索，按分组或入座状态筛选。
- 拖动宾客到圆桌中央自动选空位，或拖到指定座位；已入座宾客可以跨桌移动或互换座位。
- 拖回左侧名单取消入座；也支持点击选择宾客，再点击空位，方便手机使用。
- 自由添加、改名和删除圆桌，每桌固定 10 个座位，满桌拒绝增加人员。
- 点击圆桌中心或铅笔按钮编辑桌号（1～200），重复桌号会即时提示并禁止保存；移动、删除其他桌子不会改变已有桌号，Excel 导入导出同步使用此桌号。
- 普通圆桌视图可直接拖动圆桌中心调整桌位，空格落位、占用格交换，桌内宾客保持原座位。
- 删除桌子会将原桌宾客移回待安排，保留名单。
- 宴会厅前方舞台、中央纵向过道，两侧各支持 1～3 列圆桌。
- 点击「调整桌位」后拖动整桌到网格，自动对齐行列；空格允许移动，占用格交换桌子位置，舞台和过道禁止落位。
- 桌位调整保留桌号及本桌宾客；也可点击桌子后点击空格或另一张桌子，完成后切回宾客排座。
- 桌位布局自动保存，支持刷新恢复和撤销；新增桌子优先放入空格，超出当前行时自动扩展。
- 圆桌图与列表切换，座位图自动适配宽度并支持 60%–200% 缩放，最多撤销最近 30 步。
- 编辑婚礼名称、日期和地点，导出包含宾客座位与桌次概览的 Excel。
- 浏览器本地自动保存，刷新恢复名单和桌次。

首次进入使用空宾客名单，并提供 3 张空桌，可直接导入名单或手动添加宾客。已保存在浏览器中的名单和桌次仍会恢复；可通过页面底部的清空操作重新开始。

## Excel 格式

模板位于 `public/templates/guest-template.xlsx`，可以直接从页面下载。

第一行必须有「姓名」（也接受「宾客姓名」）列，每行一位宾客；只读取第一个工作表。其余列可选：

| 列名 | 说明 |
| --- | --- |
| 姓名 | 必填，最多 30 字 |
| 分组 | 最多 30 字，空白默认「其他宾客」，可填写自定义分组 |
| 手机号 | 最多 30 字，建议使用文本格式 |
| 备注 | 最多 200 字，可填写餐食、儿童、同桌偏好等 |
| 桌号 | 可选，1～200 的整数，对应页面第几桌；留空待安排，每桌含已有宾客最多 10 人 |

删除模板中的示例行后再填写真实名单。导入会追加宾客，同名人员作为不同宾客保留；重复导入同一文件也会重复追加。无效行会在预览中提示跳过数量。

导出的座位表可再次导入宾客信息；重新导入时按「桌号」安排到对应桌子的空位；不恢复具体座位号，满桌者保留待安排。

## 数据与项目结构

数据保存在当前浏览器的 `localStorage`（`wedding-seating:v1`）。无需后端；更换浏览器、清除浏览器数据后无法恢复，请导出 Excel 备份。撤销历史只在当前打开的页面保留。

```text
src/App.tsx          工作台、状态管理与交互
src/components.tsx   圆桌、座位、可拖动宾客、弹窗
src/Hall.tsx         宴会厅行列网格、可移动桌子、落位提示
src/dialogs.tsx      宾客表单、Excel 预览、桌次和婚礼设置
src/model.ts         排座规则、示例数据、本地数据校验
src/excel.ts         按需加载的 Excel 读取和导出
src/index.css        Tailwind 主题与圆桌样式
tests/model.test.ts  宾客排座、桌位移动与交换、列数调整及数据完整性测试
```

拖拽使用 `@dnd-kit/core`，图标使用 `lucide-react`。SheetJS 采用官方分发的 0.20.3 版本，Excel 引擎在首次导入或导出时才加载。
